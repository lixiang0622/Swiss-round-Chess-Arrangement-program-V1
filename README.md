# Swiss-round-Chess-Arrangement-program-V1

本系统是一款专为**国际象棋线下比赛**设计的瑞士轮赛事管理系统。它包含了核心的瑞士轮编排算法，支持完整的赛事生命周期管理（选手导入、自动编排、台次划分、对局结果录入、小分计算、裁判现场判罚、退赛与弃权处理以及报表导出）。

系统提供了两种运行版本，满足不同场景下的部署与使用需求：
1. **Streamlit 现代 Web Pro 版 (`app.py`)**：适合局域网多端协同或单机现代化网页交互。
2. **Tkinter 经典桌面版 (`国际象棋瑞士轮程序新版.py`)**：轻量级单机本地应用，零外部服务依赖，一键打包运行。

---

## ✨ 核心功能特性

### 1. 👥 选手管理与快捷报名
* **双渠道报名**：支持在界面中逐个添加选手，或通过 **Excel 模板**一键批量导入。
* **丰富属性支持**：选手可配置姓名、编号、学号/证件号、代表队/俱乐部、性别、组别等。
* **智能编号**：名单锁定后系统自动随机或按规则分配唯一的比赛大号。

### 2. 🧮 智能瑞士轮编排算法 (Swiss-System)
* **同分相遇原则**：严格遵循国际象棋瑞士轮核心逻辑，优先确保积分相同或相近的选手进行对阵。
* **避免重复对局**：算法自动规避在同一场比赛中已经相遇过的对手。
* **先手权（平衡执白/执黑）自动微调**：记录选手的历史执棋颜色流（Color History），在编排时尽可能平衡每位选手的执白与执黑次数，避免连续三轮执相同颜色。
* **轮空 (BYE) 智能处理**：当参赛选手为奇数时，系统自动编排一人轮空。轮空选手获得 1 分，且不会在后续比赛中重复轮空。

### 3. 📝 全功能比分录入控制台
支持线下国际象棋比赛的所有规范对局结果录入：
* **白胜 (1 - 0)**
* **黑胜 (0 - 1)**
* **和棋 (½ - ½)**
* **白方弃权 (0 - 1F)**（黑方不战而胜）
* **黑方弃权 (1F - 0)**（白方不战而胜）
* **双弃权 (0 - 0)**（两名选手均未到场或违纪）

### 4. 🥇 实时排名与科学破同分 (Tie-Breaks)
系统在每轮比赛结果录入后实时更新排行榜，并支持多种国际正规破同分规则：
1. **大分（主得分）**：胜得 1 分，和得 0.5 分，负/弃权得 0 分。
2. **索尼伯恩-伯格制 (Sonneborn-Berger, SB分)**：所有战胜对手的积分全额 + 所有战和对手积分的一半 + 裁判判罚修正，科学打破同分僵局。
3. **胜局数 (Wins)**：总胜局数多者靠前。
4. **团体计分模式（可选）**：支持计算代表队/俱乐部的团体总分（默认累加每个代表队前 $N$ 名选手的总积分）。

### 5. ⚖️ 现场裁判高级控制台 (Referee Console)
针对线下比赛中突发的现场状况，提供强有力的微调工具：
* **裁判调整分（判罚/加分）**：支持对选手进行手动扣分（如迟到、违纪、手机响铃等判罚 $-0.5$ 或 $-1$）或违规补偿分。
* **退赛与取消资格 (DQ)**：比赛中途选手因伤、因故退赛或被取消资格后，一键执行 DQ。系统在下一轮编排时会自动将其剔除，不再参与对阵。支持误操作后的一键“恢复资格”。

### 6. 📄 赛事报表专业导出
* **全赛程存档**：每轮结算后自动保存赛事进度，防丢防错。
* **PDF 现场对阵与成绩单**：基于 Matplotlib 高清渲染，支持一键导出包含实时对阵、积分榜、选手个人小分对局档案的 **PDF/图片报表**，方便裁判打印现场张贴或发送至选手群。

## 📊 生成内容示例与数据规范

为了方便赛事存档、跨平台流转以及裁判现场打印张贴，系统在赛事各个阶段会生成规范化的数据文件与可视化报表。

### 1. 🗂️ 赛事状态数据 (JSON 示例)
无论是运行 Web 版还是桌面版，系统均支持将当前赛事进度完整导保存为 `.json` 归档文件。

#### 🔹 对阵前的初始状态 (选手报名锁定后)
选手名单锁定并分配比赛大号后，`opponents`（历史对手）和 `matches`（对局流）为空：
```json
{
  "match_name": "2026年深蓝杯秋季公开赛",
  "current_round": 1,
  "total_rounds": 5,
  "players": [
    {
      "name": "张楚墨",
      "student_id": "PB230001",
      "team": "地空学院",
      "number": 1,
      "score": 0.0,
      "opponents": [],
      "matches": [],
      "color_history": [],
      "disqualified": false,
      "penalty_score": 0.0
    },
    {
      "name": "BYE",
      "student_id": "-",
      "team": "-",
      "number": 0,
      "score": 0.0,
      "opponents": [],
      "matches": [],
      "color_history": [],
      "disqualified": false,
      "penalty_score": 0.0
    }
  ]
}

```

#### 🔹 对阵结算后的状态 (例如第 1 轮结束)

此时选手的积分、破同分（SB分）、历史执棋颜色（`W` 代表白，`B` 代表黑）以及对局详情已被完整记录：

```json
{
  "current_round": 2,
  "players": [
    {
      "name": "张楚墨",
      "number": 1,
      "score": 1.0,
      "sonneborn_berger": 0.0,

      "matches": [

          "color": "W",

          "result": "1-0",

        }
      ]
    }
  ]
}
```

## 🚀 运行与使用指南

### 版本一：Streamlit 现代 Web Pro 版 (`app.py`)

拥有最现代化的响应式网页设计，支持本地运行或单机运行供多人手机扫码查看。

#### 1. 启动服务

在终端运行以下命令：

```bash
streamlit run app.py

```

启动后，浏览器会自动打开 `http://localhost:8501`。

#### 2. 操作流程

1. **选手报名标签页**：
* 输入比赛名称、总轮数，选择是否启用团体计分。
* 点击 **"下载 Excel 模板"**，填入选手后点击 **"从 Excel 导入"**。
* 检查名单无误后，点击 **"🚀 锁定名单并开始比赛"**。


2. **比赛对阵标签页**：
* 查看系统自动生成的当前轮次台次编排表。
* 在右侧的 **"比分录入控制台"** 选择台次，点击对应的比分按钮进行录入。
* 全台次录入完成后，点击底部的 **"✅ 结算本轮 -> 下一轮"**。


3. **排名与裁判标签页**：
* 实时监控当前的选手大分、SB分以及排名变化。
* 下方提供裁判操作台，可随时对指定选手进行“扣分/加分”或“退赛(DQ)”操作。
* 最后一轮结束后，系统将自动展示最终排名并锁定全场报表。



---

### 版本二：Tkinter 经典桌面版 (`国际象棋瑞士轮程序新版.py`)

无需任何浏览器或网络服务，纯本地 GUI 界面，极其适合断网环境下的单机赛事流转。

#### 1. 启动服务

直接使用 Python 运行或双击运行：

```bash
python 国际象棋瑞士轮程序新版.py

```

#### 2. 特色操作说明

* **文件菜单栏**：支持随时将当前比赛进度保存为 `.json` 文件，并支持随时导入历史赛事存档，实现断电或跨天比赛的无缝衔接。
* **状态栏实时提醒**：底部常驻提示当前进行到第几轮、当前已录入/未录入台次。

如果你想把本系统打包，发送给不具备 Python 环境的线下赛场裁判电脑上直接双击使用，可以使用 `PyInstaller`。

```bash

# 打包 Tkinter 桌面版（生成单个独立 exe 并在运行时隐藏控制台窗口）
```

## 📐 算法及存储规范说明

* **数据持久化**：系统所有的临时赛程数据、比赛状态流均可通过标准 JSON 格式进行导入导出，格式严密，字段明晰（包含选手唯一 ID、历史对手集合 `opponents`、执黑执白历史 `color_history`、判罚调整记录等）。
* **公平性保障**：编排算法基于最大化同分匹配原则，轮空规则与 DQ 规则完全吻合线下大型正规比赛（如 FIDE 瑞士轮基础排阵思想的简化工程实现）。
